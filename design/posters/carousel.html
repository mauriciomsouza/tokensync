The design decision

Compare color the way eyes do.

Not hex strings: distance in CIELAB with CIEDE2000. Under ΔE 1 counts as in sync. Above it, you see by how much.

What makes it different

Sync changes values. Nothing else.

Comments, formatting, key order and value syntax stay exactly as you wrote them. Only the drifted values move.

src/styles/tokens.csstokensync sync --write
/* Accent */
- --color-accent-default: #5b3be8;
+ --color-accent-default: #6440f0;
--color-accent-hover: #5130cc;
…
/* Radius */
- --radius-md: 6px;
+ --radius-md: 8px;

by default. --write applies.
